# View Rendering

Lantern includes a lightweight Blade-style view engine for simple HTML pages or emails.

## Directory layout
- Templates live under `resources/views`.
- Call `view("welcome")` to render `resources/views/welcome.html`.
- Add nested folders using dot/slash notation (`view("auth/login")`).

```html
<!-- resources/views/welcome.html -->
<!doctype html>
<html lang="en">
	<head>
		<meta charset="utf-8" />
		<title>{{ title }}</title>
		@vite
	</head>
	<body>
		<h1>Hello, {{ name }}!</h1>
	</body>
</html>
```

## Features
- `ViewEngine` (`@core/View/ViewEngine.ts`) loads templates via `TemplateLoader`, which caches file contents in memory. Pass `{ cache: false }` when instantiating your own loader if you want hot reloading outside of Bun's dev server.
- `@vite` placeholders inside templates are replaced with the current script/link tags generated by `ViteAssetTagGenerator`, so dev vs production assets “just work”.
- `{{ variable }}` expressions are escaped (`&`, `<`, `>`, quotes, apostrophes). Use proper HTML encoding if you need raw HTML.

## Response helper
```ts
return view("welcome", { title: "Lantern" }, { status: 201 });
```
- The helper renders HTML, sets `Content-Type: text/html; charset=utf-8`, and lets you override the HTTP status/headers.
- Combine with route params or configuration values as needed: `view("about", { appName: config("app.name") })`.

```ts
export class AboutController {
	async invoke() {
		return view("about", {
			appName: config("app.name"),
			description: "Built with Lantern",
		});
	}
}

// Custom engine usage
const engine = new ViewEngine("/custom/views");
const html = await engine.render("emails/reset-password", { url: resetUrl });
```

## App shell renderer
Inertia also uses `AppShellRenderer` (`@core/View/AppShellRenderer.ts`), which loads `assets/index.html`, replaces `@vite`, and injects `@inertia` with a JSON-escaped `<div id="app" data-page="...">`. If you customize the SPA shell, keep those tokens intact so the renderer can replace them.
